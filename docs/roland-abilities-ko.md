# 롤랑과 공방 무기 능력

결투자의 표시 이름은 롤랑, 시작 무기 Rapier의 표시 이름은 뒤랑달로 변경했다. 영웅 enum, 무기 클래스, 기본 능력치와 스프라이트는 유지한다. 기존 무기의 결투자 능력 진입점은 제거하고 MeleeWeapon과 RolandAbilities에서 공통 처리한다. 기존 세이브의 역직렬화를 위해 이전 능력의 중첩 버프 클래스와 일부 정적 보조 메서드는 남겨 두었다.

## 효과와 수치

- 묵: 무기 사거리 +2칸, 적중 후 실제 입힌 피해의 50%를 기존 출혈 시스템의 강도로 전달.
- 알라스: 최대 2칸 거리의 적에게 1칸 돌진 후 기본 공격. 인접한 적은 제자리 공격.
- 알라스 건틀릿: 최대 5칸 거리의 적 뒤로 순간이동, 신속 5턴. 별도 공격 없음.
- 느티나무: 필중 기본 공격, 취약 5턴.
- 늙은소년: 필중 기본 공격, 멍해짐 5턴으로 명중·회피 절반.
- 휠스 ATK: 1.7배 공격. 사용자가 지정한 수치.
- 휠스 DEF: 현재 무기 피해 굴림의 80%를 보호막으로 획득. 기존 보호막보다 적은 값으로 덮어쓰지 않음.
- 크리스탈: 적 뒤로 이동해 기습, 첫 공격은 0턴. 같은 무기로 능력을 재사용하면 추가 충전량 없이 원위치로 돌아와 기습하며 공격 시간 소모. 복귀 상태와 무기의 고유 식별자를 저장한다. 층 이동 시 복귀 상태 무효화. 복귀 위치가 막히면 자원 소모 없이 거절.
- 랑아: 직선/대각선 최대 5칸의 빈칸으로 순간이동. 경로의 적 각각을 0.8배로 공격. 아군 제외.
- 로직 피스톨: 3칸 이내 적을 각각 0.6배로 두 번 공격. 각 타격의 명중 및 적중 효과 별도 처리.
- 로직 샷건: 인접한 적을 1.3배로 공격하고 실제 입힌 피해의 15%를 출혈 강도로 전달. 배율은 사용자가 지정한 수치.
- 뒤랑달: 필중 기본 공격. 처치 시 최종 체력 초과 피해를 다음 명중 공격에 추가하고 힘 +2를 10턴 부여. 저장된 추가 피해는 재저장하지 않아 관성처럼 무한 누적을 막는다. 힘 증가는 중첩되지 않으며 지속 시간이 갱신된다.

정해지지 않은 피스톨·랑아 배율, 늙은소년 지속 시간은 진행 중 안내한 기본값이다. 건틀릿 이동 범위는 5칸으로 설정했다. 출혈은 기존 출혈의 저항·감쇠·지속 피해 규칙을 사용한다. 필중을 명시하지 않은 능력은 일반 명중 판정을 유지하며, 무적/절대 회피 등 기존 전투 규칙은 그대로 적용한다.

능력 설명은 노란색 제목 아래 본문과 충전량을 표시한다. 공격·이동 검증 후에만 충전량을 지불하며, 벽 통과·점유 칸 도착·비행하지 않는 영웅의 낭떠러지 도착은 허용하지 않는다. 순간이동 도착 시 기존 바닥/함정 처리를 사용한다.

## 롤랑 스프라이트 (2026-11-27 수정)

원본은 `tools/sprite-inputs/roland-idle.png`에 보존했다. 사용자가 다시 첨부한 세이버 ZIP을 직접 비교한 결과, 이전 롤랑의 임의 팔 흔들기/눈 깜박임, 단색 선으로 다시 그린 소매, 몸통 리사이즈, 바짓단 전체 이동이 차이를 만들었다.

수정본은 ZIP의 실제 `motion-report.json`을 `saber-motion-reference.json`으로 보관하고 프레임별 머리/팔/발 동작 값을 직접 읽는다. 원본 소매 픽셀을 이동하고, 몸통과 넥타이는 축소하지 않는다. 무릎을 고정하고 발끝만 움직이며, 대기 두 프레임은 원본 그대로 유지한다. 묘비 8~12는 첨부 세이버의 공통 효과 픽셀을 그대로 사용한다. 살아 있는 프레임에는 롤랑 원본 색상만 사용한다.

재생성: `python tools/animate-roland.py tools/sprite-inputs/roland-idle.png --reference tools/sprite-inputs/saber-approved-sheet.png --output 새폴더`

기존 HeroSprite의 21프레임 좌표와 재생 순서를 유지하고, 동일한 정장으로 7개 방어구 행을 만들어 `core/src/main/assets/sprites/duelist.png`에 적용했다. 원본 대기/얼굴/머리/중앙 넥타이 픽셀 보존, 서로 다른 걷기 6프레임, 147개 셀과 투명 여백, 재생성 일치를 검증했다. 비교 이미지는 세이버/수정 전/수정 후를 나란히 표시한다. 실제 게임 내 조작 검증과 APK 빌드는 하지 않았다.

## 9등급 해결사와 침묵 장갑

- 뒤랑달의 강화당 최소/최대 피해 증가량을 +2/+4로 변경했다(기존 +1/+2의 두 배).
- 사진에 표시된 롤랑 특성 이름을 적용했다. 흐트러짐은 적마다 한 번, 1레벨에서 체력 33% 이하일 때 마비 1턴, 2레벨에서 50% 이하일 때 마비 2턴이다. 보스와 소형 보스는 대신 취약 1/2턴을 받는다. 발동 여부는 적의 저장 데이터에 남는다.
- 챔피언을 9등급 해결사로 변경했다. 기존 내부 식별자는 저장 호환성을 위해 유지한다. 전직 또는 기존 저장 불러오기 시 침묵 장갑을 한 번 지급하고 기존 보조 무기를 옮긴다.
- 침묵 장갑은 무기 전용 30칸 가방이다. 가방 무기의 장착/해제/교체는 0턴이며 기존 저주 제한을 지킨다. 가득 찬 상태에서 해제하면 거절하고, 교체 시에는 새 무기가 빠진 자리에 이전 무기를 넣는다.
- 장갑을 퀵슬롯에 넣으면 무기 목록을 연다. 능력이 있는 근접 무기를 선택하면 자동 장착 후 능력을 사용한다. 능력이 없는 무기/투척 무기는 일반 아이템 행동 창을 연다. 능력 자체의 충전량과 행동 시간은 그대로 소모한다.
- 빛 회복은 기존 다채로운 충전 효과를 유지한다. 기존 챔피언의 충전 상한 +2와 충전 속도 +50%는 새 전용 가방 기능으로 대체했다.
- 차원 공명은 장갑과 손에 든 근접 무기 중 최고 단계 무기의 실제 강화 수치를 기준으로 한다. 최고 단계가 여럿이면 가장 높은 실제 강화 수치를 고른다. 1/2/3레벨은 단계 차이 2/1/0 이상에 적용한다. 원래 강화가 더 높으면 유지하며 영구 강화하거나 공유 효과를 재귀적으로 중첩하지 않는다.
- Furioso는 9개 계열(변형 ATK/DEF, 피스톨/샷건, 알라스/건틀릿은 같은 계열)의 사용 기록을 모은 후 한 번 사용한다. 기록은 저장되며 사용 시 초기화된다. 충전량 추가 소모 없이 현재 무기로 한 번의 필중 공격을 한다. 무기 사거리와 공격 시간은 유지한다.
- Furioso 1/2/3레벨: 기본 공격 2/2.5/3배, 취약 2/3/4턴, 실제 입힌 피해의 5/10/15% 출혈. 2레벨은 3턴 동안 명중·회피를 1.5로 나누고, 3레벨은 4턴 동안 절반으로 낮추며 자신에게 신속 5턴을 준다. 사용 수단은 장갑의 Furioso 행동 또는 화면의 장갑 행동 버튼이다.
- 첨부한 침묵 장갑 PNG는 원본 32×32 파일을 그대로 보존하고 전용 텍스처로 적용했다. 기존 아이템 UI에서는 16×16 크기로 표시하므로 주변 아틀라스 칸을 덮지 않는다.

검증은 핵심 Java 컴파일 및 회귀 테스트로 진행했다. 실제 Android 화면 조작은 별도 확인이 필요하다.

최종 검증: `:core:test` 50개 통과. 무료 교체/저주/가득 찬 가방/분실 소지품, 기존 보조 무기 이관, 강화 공유와 원본 강화 보존, 흐트러짐 1회 제한, Furioso 계열 합산과 저장 복원·소모 규칙을 포함한다.


## 침묵 장갑 UI 수정

- 인벤토리 탭 재배치 시 원본 32×32로 돌아가던 아이콘을 표시 크기 16×16에 맞춰 유지한다. 축소율을 반영해 중앙 배치와 비선택 탭의 잘라내기도 계산한다.
- 빠른 사용 목록에 현재 장착 무기를 포함한다. 수납 공간을 차지하거나 복제하지 않으며, 장갑이 비어 있어도 장착 무기가 있으면 목록을 연다. 이미 장착한 무기는 재장착하지 않고 능력을 사용한다.
- 장갑 인벤토리/퀵슬롯에 무기와 같은 공유 충전량을 `현재/최대`로 표시한다.
- 화면 장갑 버튼은 Furioso 준비 완료 시에만 나타나며, Furioso 사용 직후 사라진다. 평소 장갑 목록은 퀵슬롯으로 연다.
- 장착 무기 목록·저장 공간 보존, 공유 충전량 변화, 준비/미준비/사용 직후 버튼 전환을 회귀 테스트한다. Android 화면에서 실제 터치와 표시 확인은 별도 필요하다.


## 개발자 테스트 도구와 Furioso 연출 초안

- 개발자 도구에 텐구의 가면과 퓨리오소 충전 도구 즉시 지급 버튼을 추가했다. 두 아이템 모두 아이템 검색 목록에도 있다.
- 충전 도구는 개발자 모드에서 살아 있는 9등급 해결사가 Furioso 특성을 배운 경우에만 사용 가능하다. 한 개를 소모해 9개 계열 사용 기록을 모두 채우며 특성 배분과 일반 무기 충전량은 변경하지 않는다. 턴 소모는 없다.
- 지정 층 이동은 본 던전 1~26층을 받는다. 기존 RETURN 전환을 사용해 현재 층 저장, 동료 유지, 기존 목적지 로드 또는 새 층 생성 후 입구 배치를 처리한다. 기존 층을 초기화하지 않는다.
- Furioso는 실제 배우 좌표를 바꾸지 않고 별도 전체 화면 창에서 현재 스프라이트 프레임을 복제하여 연출한다. 0.45초 확대와 암전, 2.45초 좌우 급이동, 마지막 공격 후 0.18초 정지, 0.5초 복귀로 총 약 3.58초다.
- 마지막 이동이 끝날 때 기존 피해와 부가 효과를 한 번 적용하고 복귀 완료 후 공격 시간을 소모한다. 연출 중에는 입력과 턴 진행을 막는다. 강제 창 종료 시 복제 이미지를 정리하고 원래 스프라이트 표시를 복구하며, 피해 전에 중단됐다면 스택을 쓰지 않는다.
- 추가 참격/타격 이펙트, 공격 프레임, 추가 효과음은 포함하지 않았다. 참조 영상은 검색으로 찾았지만 이 환경에서 재생이 차단되어 원작 프레임/음향 타이밍을 검증하지 못했다. 현재 이동 타이밍은 합의한 연출을 바탕으로 만든 초안이며 WndFurioso의 TIMES/OFFSETS에서 조정할 수 있다.
- 핵심 회귀 테스트 57개 통과. Android에서 실제 연출 화면, 기기 회전/백그라운드 복귀, 각 보스 층 이동은 별도 실기 검증이 필요하다.

## Furioso 12단계 이동 수정

공격 구간을 5.6초로 조정했다(확대·정지·복귀 포함 약 6.73초). 사용자가 지정한 순서대로 원거리 넉백 두 번 → 관통 돌진 → 제자리 공격 → 짧게 접근 후 정지 공격 → 관통 돌진 세 번 → 제자리 두 번 공격 → 상승/하강 → X자 교차와 빠른 위치 전환 → 샷건의 큰 넉백 → 추격 후 하강 → 상승하며 반대편 이동 → 0.65초 대기 후 크게 하강한다.

무기와 공격 프레임은 추가하지 않았다. 제자리 공격은 롤랑의 위치를 유지하고 적의 작은 반동으로 타이밍만 표현한다. 내려찍기와 올려베기는 몸체의 수직 이동으로만 표현한다. 넉백도 연출용 복제 이미지에만 적용하며 실제 던전 좌표, 기존 피해량 및 마지막 타격 후 1회 피해 처리에는 영향을 주지 않는다.

첫 두 넉백, 세 번의 관통, 두 대각선 교차, 큰 넉백과 추격, 반대편 이동 및 마지막 대기 구간을 회귀 테스트로 확인한다. 실제 기기에서 체감 속도와 자연스러움은 별도 확인이 필요하다.
