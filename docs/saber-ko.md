# 세이버(5차) 1차 구현

사용자가 제공한 확정 설정 이미지를 기준으로 기존 전사의 한국어 표시를 세이버로 변경합니다.
기존 WARRIOR, 특성 enum, 장비 클래스, 저장 키, Java 패키지를 그대로 유지합니다.
기존 전사 저장 파일도 한국어에서는 세이버로 표시됩니다. 다른 언어의 이름은 아직 원본입니다.

| 구분 | 기존 | 변경 |
|---|---|---|
| 시작 근접 무기 | 낡은 소검 | 인비저블 에어 |
| 시작 투척 무기 | 투척용 돌 | 열화된 스트라이크 에어 |
| 고유 장비 | 부러진 인장 | 마력 방출(갑옷) |
| 1티어 1 | 푸짐한 식사 | 고봉밥 |
| 1티어 2 | 베테랑의 직감 | 직감 |
| 1티어 3 | 분노 자극 | 마력 방출 |
| 1티어 4 | 강철의 의지 | 열화된 대마력 |
| 2티어 1 | 강철의 위장 | 세이밥 |
| 2티어 2 | 액체로 이루어진 의지 | 용의 노심 |
| 2티어 3 | 상형문자 전이 | 원탁의 기사 |
| 2티어 4 | 치명적인 관성 | 승리의 기세 |
| 2티어 5 | 급조한 투척물 | 랜슬롯의 흉내 |

고봉밥은 식사 직전 체력이 최대 체력의 **70% 이하**이면 +1에서 4, +2에서 6을
회복합니다. 70% 경계값을 포함하며 정수 비교를 사용합니다. 예를 들어 최대 체력 20에서는
14일 때 발동하고 15일 때 발동하지 않습니다. 다른 직업이 특성 변환으로 얻어도 같은
특성 효과를 적용합니다. 다른 언어의 해당 특성 설명에도 70%를 반영했습니다.

그 외 장비의 수치, 투척 수량, 방어막/강화/상형문자 전이, 특성 순서 및 효과는 유지합니다.
장비 클래스의 표시 이름 변경이므로 도감과 기존 저장에 들어 있는 같은 장비에도 적용됩니다.
마력 갑옷의 부착/분리/상형문자 선택 UI와 방어막 상태 설명도 함께 변경합니다.

이번 범위는 이름·설명 및 명시된 체력 조건입니다. 세이버 전용 도트, 초상화,
3티어 이상 및 전직/갑옷 능력의 재설계, NPC 대사와 세계관 전체 개작은 포함하지 않습니다.
이미지의 인물 사진을 게임 스프라이트로 사용하지 않았습니다.

## 검증 및 기기 확인

master 반영 시 기존 Android Debug APK 워크플로가 APK를 빌드합니다.
설치 및 다운로드 방법은 [Android 빌드 안내](android-build-ko.md)를 참고하세요.

기기에서는 한국어 설정에서 다음을 확인할 수 있습니다.

1. 영웅 선택에 세이버와 새 장비 설명이 표시되는지 확인합니다.
2. 시작 무기/투척 무기/갑옷의 정보창을 열어 이름을 확인합니다.
3. 고봉밥 +1/+2를 찍고 체력 70% 이하에서 각각 4/6이 회복되는지 확인합니다.
4. 70% 초과에서는 고봉밥 추가 회복이 없는지 확인합니다.
5. 마력 갑옷을 분리/부착해 강화와 상형문자 전이가 기존대로 동작하는지 확인합니다.
6. 저장 후 다시 실행해 장비와 특성 포인트가 유지되는지 확인합니다.

실기기에서 위 플레이 시나리오를 실행한 결과는 별도 검증이 필요합니다.
