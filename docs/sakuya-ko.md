# 사쿠야 시작 장비

도적의 내부 식별자 ROGUE와 전직·특성은 유지하고 한국어/영어 표시 이름을 사쿠야/Sakuya로 변경합니다.

- 새 게임 시작 유물: 사쿠야의 회중시계. 기존 TimekeepersHourglass를 지급하며 같은 게임에서 모래시계가 다시 생성되지 않도록 유물 생성 목록에서 제외합니다. 기존 시간 정지·충전·모래 주머니 강화 규칙과 아이콘은 유지합니다. 모래시계의 표시 이름은 기존 저장 아이템에도 적용됩니다.
- 새 게임 시작 원거리 무기: 홍마관의 나이프. SpiritBow를 상속하며 영혼의 활의 피해·레벨 성장·무제한 발사 규칙을 사용합니다. 아이템과 투사체 이미지는 모두 기존 THROWING_KNIFE입니다. 사냥꾼은 기존 영혼의 활로 시작합니다.
- 퀵슬롯 1은 회중시계, 퀵슬롯 2는 나이프입니다. 단검과 다른 시작 장비는 유지합니다.
- 기존 진행 중인 게임의 망토/투척용 나이프를 자동 변환하지 않습니다.
- 망토 전용 특성은 기존 조건을 유지하므로 회중시계만으로 발동하지 않습니다. 특성 재설계는 이번 변경에 포함하지 않습니다.

소스와 번역 키 정합성, 변경 형식을 점검했습니다. 빌드와 실행 테스트는 수행하지 않았습니다.

## 사쿠야 스프라이트

사용자가 제공한 실제 12×15 RGBA PNG를 `tools/sprite-inputs/sakuya-idle.png`에 보존했습니다.
`tools/animate-sakuya.py`는 세이버의 연결형 픽셀 변형 생성기를 기반으로 하며,
기존 사용자 제공 동작 참조 시트 `tools/sprite-inputs/animation-reference.png`를 사용합니다.
머리·얼굴·리본 영역의 경계를 사쿠야 도트에 맞춰 조정했습니다. 기본 프레임은 원본과
RGBA 픽셀이 같으며 모든 불투명 픽셀은 원본 팔레트에서 가져옵니다.

```sh
python tools/animate-sakuya.py tools/sprite-inputs/sakuya-idle.png --reference tools/sprite-inputs/animation-reference.png --output /tmp/sakuya-new-output
python tools/check-hero-sprite.py /tmp/sakuya-new-output/sakuya-sheet.png
```

출력 디렉터리는 존재하지 않아야 합니다. 생성기는 게임 리소스를 직접 덮어쓰지 않습니다.
검토한 최종 시트를 `core/src/main/assets/sprites/rogue.png`에 반영했습니다.
256×128 시트의 각 12×15 프레임은 `(12*프레임번호, 15*갑옷단계)`에 배치되며,
21프레임을 7줄에 동일하게 반복합니다. 갑옷을 변경해도 같은 사쿠야 복장을 유지합니다.

대기 0~1, 이동 2~7, 사망 8~12, 공격 13~15, 상호작용 16~17, 비행 18,
읽기 19~20의 기존 코드 순서를 유지합니다. 사망은 참조 시트의 묘비 실루엣을
사쿠야 원본의 중립색 팔레트로 표현합니다. 팔다리 동작은 제한된 픽셀 변형으로 근사하며
별도의 무기·책 소품이나 초상화는 생성하지 않았습니다.

147칸 배치, 7줄의 원본 대기 프레임 일치, 팔레트 보존, 이동 실루엣 변화,
투명 여백, GIF 디코딩 및 제공 ZIP 무결성을 검사했습니다. 게임 실행과 APK 빌드는 하지 않았습니다.


### V2 도트 재적용

입력을 사용자 제공 sakuya_ver2.png로 교체했습니다. 앞선 몸통 압축과 치마의 팔 영역 변형을 제거했습니다.
사망을 제외한 모든 프레임에서 y=0..8 머리·얼굴·목 부분과 y=12 치마 단은 원본 그대로입니다.
손목과 발만 별도로 배치하며, 대기·걷기·공격·상호작용·읽기 동작에 작은 포즈 변화를 줍니다.
0번 프레임은 V2 원본과 완전히 같고, 7개 갑옷 줄에 동일한 21프레임을 적용했습니다.
사망은 기존 참조 시트의 묘비 방식입니다. 파일 규격, 보호 영역 픽셀 일치, GIF 및 ZIP 검증을 통과했습니다.


### 참조 시트 기준 재작업 (현재 적용본)

다시 첨부한 asdfasdf.png와 sakuya_ver2.png를 입력으로 사용합니다. 이전 V2의 손목 왕복 동작을 제거했습니다.
이동 2~7번의 하단 두 행 실루엣은 참조와 정확히 같고, 상체 수직 이동은 참조 머리 패치 매칭으로 측정한 0,0,1,0,0,1픽셀입니다.
상체는 크기를 바꾸지 않고 통째로 이동합니다. 대기는 참조의 고개 돌리기, 비행은 참조의 발 모양을 반영했습니다.
공격은 붉은 잔상과 신체를 구분해 오른손 내밀기·올리기·가로지르기로 해석했습니다. 이 부분은 참조 픽셀을 그대로 복사한 것이 아닌 수동 포즈 근사입니다.
읽기는 참조의 두루마리 영역을 사쿠야 팔레트로 옮겼습니다. 사망은 기존 묘비 방식입니다.
147칸 배치, 입력 기본 프레임 일치, 이동 발 실루엣 일치, 상체 높이, GIF/ZIP 무결성을 검사했습니다.
원본과 결과를 같은 프레임 번호·재생 속도로 나란히 비교하는 GIF를 제공합니다. 실기기 확인은 하지 않았습니다.


### 두 ZIP 비교 후 최종 수정

앞선 참조 마스크 적용 버전을 대체합니다. 첨부 세이버 완성본의 동작 순서에 맞춰 머리 반전과 두루마리 오버레이를 제거했습니다. 치마 밑단 원본 픽셀은 유지하고 신발을 치마 뒤에서 움직입니다. 공격과 상호작용은 세이버의 팔 방향을 사용하되 사쿠야 소매와 손을 연결했습니다.
원본 대기, 머리·치마 불투명 픽셀 보존, 팔레트, 147칸, GIF/ZIP 검증을 통과했습니다. `sakuya-corrected-sprites.zip`에 비교 이미지와 재현 입력/스크립트를 포함했습니다. 게임 실행·APK 빌드·푸시는 하지 않았습니다.
