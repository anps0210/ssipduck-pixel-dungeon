# 엑스칼리버와 개발자 모드

## 엑스칼리버 조합

연금술 솥에 감정된, 저주받지 않은 아래 두 장비를 넣습니다. 착용 중이면 먼저 해제하세요.

- 인비저블 에어: 영구 강화 수치가 정확히 +5, 강화 주문서 사용 기록 5회 이상.
- 아발론: 정확히 +10.
- 연금술 에너지: 50.

두 재료를 모두 소모하고 감정된 **엑스칼리버 +0**을 하나 만듭니다.
재료의 강화, 마법, 증강은 결과물에 이전하지 않습니다. 임시 강화나 저주 주입의
표시 강화 수치만으로 조건을 채울 수 없습니다. +6 인비저블 에어는 해당하지 않습니다.

엑스칼리버는 일반 5단계 검으로, +0 기본 피해량은 5~30이고 기본 힘 요구치는 18입니다.
강화 시 기존 일반 근접 무기 공식을 사용합니다. 충전과 장착 패시브는 아래에 설명하며, 충전 소비 능력과 결투자 능력은 아직 없습니다.
이미지는 임시로 기존 대검 아이콘을 사용합니다. 새 클래스이므로 저장 후에도 유지됩니다.

이번 버전부터 인비저블 에어에 사용한 강화 주문서 횟수를 저장합니다. 이전 버전의
저장 파일에는 출처 기록이 없으므로 기존 영구 강화 수치를 사용 기록으로 인정합니다.
개발자 도구에서 강화 수치만 지정한 새 무기는 이 기록이 없으므로, 주문서를 실제로
사용하거나 아래 '엑스칼리버 조합 재료 받기' 기능을 사용하세요.

## 개발자 모드

**설정 → 데이터 탭 → 개발자 모드 (체력 감소 방지)**에서 켜거나 끕니다.
기본값은 꺼짐이며 앱 설정에 보관되어 다른 저장 슬롯에도 적용됩니다.
켜진 동안 피해와 직접 사망 처리를 막습니다. 해제하면 즉시 일반 규칙으로 돌아갑니다.
이는 상태이상, 이동 제한, 갑옷 요구 힘까지 없애는 모드는 아닙니다.

모드를 켠 뒤 던전의 **게임 메뉴 → 개발자 도구**를 엽니다.

- 아이템 얻기: 한국어 이름 또는 영문 클래스 이름으로 검색합니다. 빈 검색은 전체 목록입니다.
  5개씩 페이지를 넘겨 선택한 다음 `수량,강화`를 입력합니다. 예: `1,5`.
  수량 1~99, 일반 강화 0~20, 유물 표시 강화 0~10을 지원합니다.
  감정된 아이템을 지급하고 가방이 가득 차면 발밑에 놓습니다.
- 적 소환: 33종 일반 몬스터 중 선택한 뒤 시야 안의 빈 바닥을 누릅니다.
  벽, 낭떠러지, 점유된 칸에는 소환하지 않습니다. 대형 적은 넓은 칸이 필요합니다.
  전용 층의 기믹을 요구하는 보스/퀘스트 제어 몬스터는 목록에서 제외했습니다.
- 엑스칼리버 조합 재료 받기: 조건을 충족하는 인비저블 에어 +5, 아발론 +10,
  에너지 50을 지급합니다. 연금술 솥에서 실제 조합을 시험할 수 있습니다.
- 연금술 에너지 +50: 연금술 시험에 필요한 에너지를 추가합니다.

아이템 목록은 335개 후보 중 추상 클래스와 기본 생성자가 없는 항목을 걸러 표시합니다.
생성된 아이템과 몬스터는 기존 게임 저장에 포함됩니다. 개발자 모드에서 한 행동도
통계와 업적에 영향을 줄 수 있습니다.

## 검증

CI에서 조합의 정확한 강화 조건, 주문서 출처 기록 저장/복구, 잘못된 재료 거절,
재료 소모, 결과물 피해량, 개발자 모드 기본값과 피해/사망 방지를 자동 테스트합니다.
그 후 APK를 빌드하고 고정 서명을 검증합니다. 실기기 메뉴 조작과 전체 아이템별
효과는 별도 플레이 확인이 필요합니다.

아발론은 기존 피의 성배의 표시 이름과 설명을 변경한 것입니다. 내부 클래스와 저장 키,
기존 강화 비용과 회복 조건을 유지합니다. 마력 동조는 기존 찌르기와 동일하게 체력을 소모하며,
별도의 무적 효과는 추가하지 않았습니다. 아이콘은 아직 기존 성배 이미지입니다.

아발론은 힘을 잃은 상태이며 체력을 바치는 동조로 본래의 힘을 되찾습니다.
장착 시 영구 강화 수치 1당 최대 체력 +2(+10에서 +20)를 제공합니다.
이 보너스는 힘의 반지 배율 적용 후 더하며, 장착/강화는 현재 체력을 회복하지 않습니다.
해제 시 보너스를 제거하고 현재 체력이 새 최대 체력을 초과하면 새 최대치로 제한합니다.
저장 복구와 재활성화에서도 보너스는 중복되지 않습니다.
아발론의 자연 재생 및 충전 회복은 기존 대비 1.05배입니다. 기아/마법 무효화/저주에
의한 기존 회복 제한은 유지하며 다른 물약과 주문의 회복량은 변경하지 않습니다.


### 엑스칼리버 충전과 패시브

- 장착 중 게임 시간 1턴마다 1% 충전, 최초 0%, 상한 100%. 가방에서는 충전하지 않으며 장착 해제/저장/불러오기 시 충전량을 유지합니다. 보조 무기 슬롯도 장착으로 취급합니다.
- 충전 소비 능력은 아직 없으며 기본 공격과 패시브는 충전량과 무관합니다. 기존 5단계 무기의 피해량과 공격 동작은 유지합니다.
- 최대 체력 +16: 재료인 아발론 +10의 +20보다 20% 낮습니다. 무기 강화 수치와 무관한 고정 보너스이며 장착/재장착으로 현재 체력을 회복하지 않습니다. 해제 시 현재 체력은 새 최대 체력을 초과할 수 없습니다.
- 자연 회복 속도 기본의 4배: 아발론 +10의 약 5.25배보다 낮습니다. 굶주림·회복 차단·마법 면역과 소금 큐브의 기존 규칙을 유지합니다. 에너지의 반지는 아발론의 회복에만 기존대로 적용됩니다. 직접 회복 아이템의 회복량은 변경하지 않습니다.
- 아발론과 함께 장착하면 회복은 더 강한 쪽만 적용하고, 저주받은 아발론의 회복 속도 저하는 유지합니다. 최대 체력은 합산합니다. 엑스칼리버 두 자루의 패시브는 중첩되지 않으며 각 무기의 충전량은 별도로 유지합니다.
- 예전 저장의 엑스칼리버는 충전 0%로 시작합니다. 기존 클래스명과 조합 조건은 유지합니다.


## 통합 빌드 v923

아발론·엑스칼리버·랜서·사쿠야 변경과 최종 도트를 포함해 JDK 17 / Android SDK 36으로 `:core:test :android:assembleDebug`를 실행했습니다. 자동 테스트 12개가 통과했으며, 고정 디버그 서명 지문 일치와 APK 내 리소스 460개의 원본 일치를 검증했습니다. 버전 코드는 923입니다. 실기기 플레이 검증은 별도입니다.
