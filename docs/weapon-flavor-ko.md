# 한국어 무기 이름과 설명

2026-11-25: 사용자가 지정한 무기 18종의 이름과 짧은 배경 설명을 `items_ko.properties`에 반영했다. 괄호 안 작품명은 아이템 이름에 넣지 않았다. 설명은 원문 인용이 아닌 팬게임용 창작 문장이다. 기존 능력 안내에 남은 옛 무기명은 '이 무기'로 정리했다. 수치, 능력, 이미지, Java 클래스 및 저장 식별자는 변경하지 않았다.

총기·사복검 등의 원작 외형은 배경 설명일 뿐, 사격이나 변형 등의 새 기능을 뜻하지 않는다. '잊혀진 자의 책상'은 사용자가 지정한 로스트 원의 호곡 모티프를 바탕으로 창작했으며 공식 아이템 설정으로 취급하지 않는다. 기타와 존 팔루스티프 경의 문장도 팬게임 분위기에 맞게 각색했다. 하나코 나나의 총기 이름은 자료에서 '사랑'으로 소개되지만 사용자가 지정한 '사랑이' 표기를 유지했다.
