# 세이버 게임용 스프라이트 제작 규격

실제 `HeroSprite.java`, `Hero.tier()`, `CharSprite.turnTo()`, `TextureFilm.java` 및
`core/src/main/assets/sprites/warrior.png`를 확인한 결과입니다.
컨셉 이미지의 크기가 아니라 아래 게임 좌표에 맞춰 제작해야 합니다.

## 확정 규격

| 항목 | 값 |
|---|---|
| 교체 대상 | `core/src/main/assets/sprites/warrior.png` |
| 전체 이미지 | 256 × 128 픽셀, 투명 PNG |
| 한 프레임 | **12 × 15 픽셀** |
| 사용 영역 | 가로 21칸 × 세로 7줄 = 252 × 105 픽셀 |
| 프레임 번호 | 0부터 20까지 |
| 좌표 | 프레임 n, 갑옷 줄 t의 왼쪽 위는 `(12*n, 15*t)` |
| 여백 | 오른쪽 4픽셀 및 y=105 이후 영역은 원본에서 투명 |
| 방향 | 오른쪽 기준, 왼쪽 이동/공격 시 수평 반전 |

원본의 프레임 0은 각 줄에서 x=1..11, y=0..14에 불투명 픽셀이 있습니다.
이는 원본 분석값이지 새 캐릭터의 모든 픽셀을 채우라는 뜻은 아닙니다.
발 위치와 머리 높이, 동작별 무게중심을 원본에 맞추고 셀 밖으로 넘기지 마세요.
프레임 사이에 별도 간격을 추가하면 안 됩니다.

## 갑옷별 줄

| 줄 t | y 범위(포함) | 외형 |
|---|---|---|
| 0 | 0–14 | 갑옷 없음 |
| 1 | 15–29 | 천 갑옷, 시작 상태 |
| 2 | 30–44 | 가죽 갑옷 |
| 3 | 45–59 | 사슬 갑옷 |
| 4 | 60–74 | 미늘 갑옷 |
| 5 | 75–89 | 판금 갑옷 |
| 6 | 90–104 | 직업 전용 갑옷 |

`Hero.tier()`는 실제 장착 갑옷으로 줄을 고릅니다. 하나의 줄만 교체하면 갑옷을
바꿀 때 원본 전사의 모습이 다시 나타납니다. 최종 시트에는 7줄이 모두 필요합니다.
`HeroSprite.tiers()`는 도적 시트의 크기로 공통 좌표를 만들기 때문에 전사 시트만
크기를 임의로 늘리는 방식은 맞지 않습니다.

## 동작과 재생 순서

| 동작 | 프레임 번호 순서 | 초당 프레임 | 반복 |
|---|---|---:|---|
| 대기 | 0,0,0,1,0,0,1,1 | 1 | 예 |
| 이동 | 2,3,4,5,6,7 | 20 | 예, 달리기 효과로 속도 변경 가능 |
| 사망 | 8,9,10,11,12,11 | 20 | 아니오 |
| 공격/마법 발사 | 13,14,15,0 | 15 | 아니오 |
| 상호작용 | 16,17,16,17 | 8 | 아니오 |
| 비행/점프 | 18 | 1 | 예 |
| 읽기 | 19,20,20,20,20,20,20,20,20,19 | 20 | 아니오 |

필요한 그림은 줄당 21장, 전체 147칸입니다. 재생 순서에 같은 번호가 반복된다고
그만큼 별도 그림을 만들 필요는 없습니다. 위 동작은 8방향 애니메이션이 아닙니다.
대기 0은 오른쪽을 향한 약간 비스듬한 기본 자세를 기준으로 원본과 비교하세요.

## 세이버 기준 도트 제작 순서

1. 시작 상태인 `(x=0,y=15,w=12,h=15)` 한 칸을 먼저 제작합니다.
2. 금발, 청색 의상, 은색 갑옷을 작은 색 덩어리로 구분합니다. 세부 얼굴보다
   실루엣과 머리/몸/발의 가독성을 먼저 확인합니다. 반투명 가장자리와 블러는 피합니다.
3. 원본 배율과 정수배 최근접 확대에서 모두 확인합니다. 큰 컨셉 이미지를 단순 축소해
   완성품으로 취급하지 않습니다. 무기나 머리카락이 옆 프레임에 침범하지 않게 합니다.
4. 기준 도트에서 대기 1과 이동 2–7을 만들고, 공격·상호작용·비행·읽기·사망을 만듭니다.
5. 얼굴과 체형은 유지하면서 갑옷 줄 0 및 2–6의 외형을 완성합니다.
6. 최종 256×128 PNG를 검증한 후 게임에 적용하고, 모든 갑옷/동작/좌우 반전을 확인합니다.

캐릭터 외곽을 넘는 검격·바람 연출은 별도 효과로 검토해야 합니다. 프레임 폭을
늘려 해결하면 공통 캐릭터 렌더링과 UI까지 영향을 줄 수 있습니다.

## 다른 이미지와의 구분

- `splashes/warrior.jpg` (800×450): 캐릭터 일러스트. 게임 이동 도트와 별개입니다.
- `sprites/avatars.png` (256×32): 별도 장면에서 사용하는 이미지이며, 일반 게임 HUD의
  영웅 초상과 동일한 파일이 아닙니다.
- `HeroSprite.avatar()`는 게임 시트에서 해당 갑옷 줄의 `(x=1,y=0,w=12,h=15)` 구역을
  잘라 UI에 표시합니다. 이 영역은 프레임 0에서 한 픽셀 오른쪽으로 이동한 구역이므로
  새 시트를 제작하면 HUD 가장자리도 확인해야 합니다.

## 검증 도구

저장소 루트에서 실행합니다. Pillow가 필요합니다.

```sh
python3 tools/check-hero-sprite.py
python3 tools/check-hero-sprite.py /path/to/candidate.png
```

크기, PNG 형식, 투명도, 147개 프레임의 비어 있음 및 여백 침범을 검사합니다.
검사를 통과해도 디자인 품질이나 게임 내 동작이 보장되는 것은 아닙니다.
현재 게임 이미지는 변경하지 않았으며 이 문서는 제작 기준입니다.
