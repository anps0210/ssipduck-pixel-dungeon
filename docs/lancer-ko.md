# 메마른 장미: 랜서

소환수의 내부 GhostHero 클래스, 장미 연결과 장비·소환·재충전 규칙을 유지하고 표시 이름을 랜서로 변경합니다. 스프라이트는 기존 유령을 유지합니다. 던전 퀘스트 NPC인 슬픈 유령은 변경하지 않습니다.

- 화살막이의 가호: 직접 원거리 피해에 0.1을 곱해 정수 반올림합니다. 4 이하의 작은 피해는 0이 될 수 있습니다. 비인접 캐릭터의 공격, 영웅의 투척 무기, 흑마법사/주술사/DM-100의 볼트, 악마의 눈 광선, 수정 위습 광선, 요그 주먹의 빛/어둠 투사체, 놀 지질학자의 바위가 해당합니다. 영웅의 긴 사거리 근접 무기, 지속 피해, 장미 미장착에 따른 소멸 피해는 제외합니다.
- 전투속행: 소환당 한 번, 체력이 0 이하가 되면 최대 체력의 절반(정수 나눗셈)+4 보호막을 얻습니다. 체력은 0인 채로 전투를 지속하며 공격 간격이 절반이 됩니다. 이동 속도와 공격력은 그대로입니다.
- 보호막은 게임 시간 1턴마다 4씩 감소합니다. 피해로도 소모되며, 0이 되면 사망합니다. 발동 여부와 남은 보호막은 저장됩니다. 새로 소환하면 다시 발동할 수 있습니다.
- 실제 사망 시 GLog.n으로 빨간색 “랜서가 죽었다!”를 한 번 출력합니다. 전투속행 발동 시에는 사망 로그를 출력하지 않습니다.
- 퀘스트·기존 대사는 별도로 재작성하지 않았습니다.

회귀 테스트를 추가했지만 빌드 및 테스트 실행은 하지 않았습니다.
